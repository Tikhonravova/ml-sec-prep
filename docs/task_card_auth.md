# Карточка постановки: аутентификация

## Вариант A: классификация
1. Пользователь и точка решения: аналитик SOC, через 5 минут после закрытия окна.
2. Объект анализа: один IP за 5-минутное окно.
3. Границы объекта: окно фиксированной длины, начало кратно 5 минутам.
4. Целевая переменная: признак «подтверждённая атака» (да или нет), известный только после расследования.
5. Тип задачи: бинарная классификация.
6. Вывод и действие: оценка риска от 0 до 1, аналитик решает, проверять ли IP. Автоблокировки нет.
7. Признаки: число неудач, число разных учётных записей, доля неудач.
8. Нельзя: итог расследования и любая информация после закрытия окна.
